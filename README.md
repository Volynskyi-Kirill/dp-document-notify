# DP Document Queue Monitor

Легковесный скрипт на Python для локального мониторинга свободных мест в электронной очереди украинского государственного сервиса (ДП Документ).

## Особенности
- Использует **Playwright** (sync API) для эмуляции реального браузера.
- Браузер и контекст сессии (Cookies) запускаются только **один раз**, что минимизирует риск блокировки.
- Окно браузера отображается (`headless=False`), чтобы при первом запуске или в процессе работы можно было вручную пройти антибот защиту (капчу).
- Случайные "человекоподобные" задержки (1.5 – 3.5 сек) между взаимодействиями со страницей.
- Автоматическая отправка уведомлений в Telegram при возможном появлении свободных мест.
- Отказоустойчивость: при ошибках `Too many requests` или временном падении сайта скрипт не завершается, а уходит в сон (с адаптивным увеличением времени ожидания).

## Требования
- **Python 3.11+**
- **[uv](https://github.com/astral-sh/uv)** (современный и сверхбыстрый пакетный менеджер)

## Установка и настройка

1. **Инициализация проекта**
   В корневой папке проекта выполните следующие команды, чтобы инициализировать проект и закрепить версию Python:
   ```bash
   uv init
   uv python pin 3.11
   ```

2. **Установка зависимостей**
   `uv` автоматически создаст виртуальное окружение (`.venv`) и установит необходимые библиотеки:
   ```bash
   uv add playwright python-dotenv requests
   ```

3. **Установка движка браузера для Playwright**
   Скрипт использует Chromium:
   ```bash
   uv run playwright install chromium
   ```

4. **Настройка конфигурации**
   Скопируйте шаблон переменных окружения:
   ```bash
   cp .env.example .env
   ```
   Отредактируйте файл `.env`, добавив свои данные:
   - `BOT_TOKEN` — токен вашего Telegram-бота (получить можно у [@BotFather](https://t.me/BotFather)).
   - `CHAT_ID` — ваш Telegram ID (получить можно у [@userinfobot](https://t.me/userinfobot) или аналогичного).
   - `MIN_SLEEP_SECONDS` и `MAX_SLEEP_SECONDS` — диапазон ожидания в секундах между неудачными попытками найти место (чтобы не спамить сайт).

## Запуск

Запускать скрипт нужно через менеджер `uv`:

```bash
uv run main.py
```

## Как это работает?
1. **Старт и Капча:** Открывается стартовая страница очереди. Вы видите окно браузера. Если Cloudflare или другой антифрод запросит капчу — проходите её вручную. Цикл пойдет дальше.
2. **Взаимодействие:** Скрипт выбирает страну (Німеччина), затем центр (Кельн) и нажимает кнопку продолжения. Перед каждым шагом выдерживается небольшая рандомная пауза.
3. **Проверка результата:** Скрипт ждет до 7 секунд появления блока с текстом `Наразі всі місця зайняті`.
   - Если текст **найден**: мест нет. Скрипт логирует это, "засыпает" на случайное время из диапазона в `.env`, затем перезагружает страницу и повторяет цикл.
   - Если текст **не найден** за таймаут: скрипт проверяет страницу на ошибки блокировки (типа `429` или `Too many requests`). Если явной ошибки нет, считается, что нас пропустило дальше (место есть), и скрипт немедленно отправляет сообщение в Telegram.
4. **Обработка ошибок:** В случае любого сбоя в цикле `try-except` (например, сайт полностью лег), скрипт умножает базовое время сна на счетчик ошибок (до 1 часа) и просто ждет, пока сайт не оживет, после чего переоткрывает стартовую страницу.
