# DP Document Queue Monitor

Легковесный скрипт на Python для локального мониторинга свободных мест в электронной очереди украинского государственного сервиса (ДП Документ).

## Особенности
- Использует **Playwright** (sync API) для эмуляции реального браузера.
- Использует **ваш настоящий системный Google Chrome** в изолированном профиле, что в сочетании с антибот-флагами и отключением свойства `webdriver` позволяет 100% обходить Cloudflare и "Too many requests".
- Браузер и контекст сессии (Cookies) запускаются только **один раз**, что минимизирует риск блокировки.
- Случайные "человекоподобные" задержки (1.5 – 3.5 сек) между взаимодействиями со страницей.
- Автоматическая отправка уведомлений в Telegram при возможном появлении свободных мест.
- Отказоустойчивость: при падениях сайта скрипт не завершается, а уходит в сон с адаптивным увеличением таймаута.

## Требования
- **ОС Windows** (скрипт оптимизирован для запуска нативной версии Chrome, из-под WSL Cloudflare может блокировать доступ).
- Установленный **Google Chrome** (по умолчанию `C:\Program Files\Google\Chrome\Application\chrome.exe`).
- **Python 3.11+**
- **[uv](https://github.com/astral-sh/uv)** (современный и сверхбыстрый пакетный менеджер).

## Установка и настройка (Windows)

1. **Клонирование репозитория**
   Убедитесь, что вы клонируете проект на файловую систему Windows (например, диск `D:` или `C:`), а не внутрь подсистемы WSL, и откройте терминал Windows (PowerShell, CMD или Git Bash).
   ```bash
   git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
   cd dp_document_notify
   ```

2. **Установка зависимостей**
   В проекте уже настроены `pyproject.toml` и `uv.lock`. Просто выполните команду синхронизации:
   ```bash
   uv sync
   ```
   *(`uv` сам скачает нужную версию Python и установит все пакеты. Устанавливать Playwright-браузеры отдельно не нужно, так как мы используем ваш локальный системный Chrome!)*

4. **Настройка конфигурации**
   Скопируйте шаблон переменных окружения:
   ```bash
   cp .env.example .env
   ```
   Отредактируйте файл `.env`, добавив свои данные:
   - `BOT_TOKEN` — токен вашего Telegram-бота (от @BotFather).
   - `CHAT_ID` — ваш Telegram ID (от @userinfobot).
   - `MIN_SLEEP_SECONDS` и `MAX_SLEEP_SECONDS` — диапазон ожидания в секундах между проверками (чтобы не спамить сайт).

## Запуск

Запускать скрипт нужно в терминале Windows:

```bash
uv run main.py
```

## Как это работает?
1. **Старт и Капча:** Открывается новое, независимое окно вашего реального браузера Chrome. Вы видите окно браузера. Если при первом запуске Cloudflare запросит капчу — проходите её вручную.
2. **Сессия:** Пройденная капча и cookies автоматически сохранятся в локальную папку `browser_profile`. При последующих запусках скрипта капчи уже не будет. Ваш основной браузер при этом не затрагивается и закрывать его не нужно.
3. **Взаимодействие:** Скрипт выбирает страну (Німеччина), затем центр (Кельн) и нажимает кнопку продолжения с рандомными паузами.
4. **Проверка результата:** Скрипт ждет появления блока `Наразі всі місця зайняті`. Если мест нет, уходит в паузу и перезагружает страницу. Если текста нет — отправляет уведомление в Telegram.
